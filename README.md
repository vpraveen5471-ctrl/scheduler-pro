# SchedulePro

SchedulePro is a host and guest scheduling app inspired by Calendly.

## Run locally

Use Node.js 20 or newer, then run:

```bash
npm start
```

Open the host dashboard at `http://localhost:3000/index.html` and the guest booking page at `http://localhost:3000/booking.html`.

## Deployment note

This version stores local demo data in `data.json`. Replace that storage with a production database before deploying a public booking service.
